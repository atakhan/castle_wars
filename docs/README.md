# Документация проекта

Папка `docs/` (ранее `gdd/`) содержит системные документы проекта и описание текущей реализации геймдизайна.

## Системные документы

- **[PROJECT_CONSTITUTION.md](PROJECT_CONSTITUTION.md)** — конституция проекта: сущность игры, принципы, границы дизайна и разработки.
- **[PROJECT_AXIOMS.md](PROJECT_AXIOMS.md)** — системные аксиомы: фундаментальные свойства мира, армии и симуляции.

## Текущий геймдизайн (реализованное)

В **[current_game_design/](current_game_design/)** лежат документы, которые описывают только то, что уже реализовано на текущий момент:

- **[current_game_design/game-design.md](current_game_design/game-design.md)** — игровой геймдизайн: механики, мир, сущности, управление, взаимодействие и интерфейс с точки зрения игры и игрока.
- **[current_game_design/technical.md](current_game_design/technical.md)** — техническая реализация: архитектура, ECS, сеть, pathfinding (A* по сетке), prediction, interpolation, reconciliation, визуализация.
