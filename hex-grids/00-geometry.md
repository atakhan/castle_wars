# Геометрия гексагона

Один правильный гексагон задаётся размером **size** — расстоянием от центра до вершины (радиус описанной окружности). Расстояние от центра до середины ребра (вписанная окружность) = size × √3/2.

---

## Spacing (шаги между гексами)

Расстояния между центрами соседних гексов в сетке.

### Flat top (плоская грань сверху)

- **width** = size × 2 (расстояние между центрами по горизонтали между «соседними по строке» гексами)
- **height** = √3 × size (между строками)
- **horiz** = width × 3/4 = size × 3/2 (шаг по горизонтали к соседу)
- **vert** = height

### Pointy top (острый угол сверху)

- **width** = √3 × size
- **height** = size × 2
- **horiz** = width
- **vert** = height × 3/4 = size × 3/2

---

## Angles (углы)

Углы от центра гекса к вершинам (для отрисовки полигона).

### Flat top

Вершины: 0°, 60°, 120°, 180°, 240°, 300°.

### Pointy top

Вершины: 30°, 90°, 150°, 210°, 270°, 330°.

В Layout это задаётся через **start_angle** (в долях 1/6 круга): 0 для flat, 0.5 для pointy (30°).

---

## Связь с Layout

- В **Layout.size** хранится масштаб: для равностороннего гекса это половина высоты (pointy) или половина ширины (flat). Можно задать разные scale по x и y для вытянутых спрайтов.
- Для спрайтов W×H:
  - Pointy: `size = Point(W/√3, H/2)`
  - Flat: `size = Point(W/2, H/√3)`
